# End-to-End Construction Management & Resource Booking Platform

The complete project codebase, documentation, database schemas, tests, and Postman collections are located in:
📂 **[`construction-management-platform/`](./construction-management-platform/)**

### Quick Start:
```bash
# 1. Navigate into project backend
cd construction-management-platform/backend

# 2. Install dependencies
npm install

# 3. Initialize MySQL Database & Seed Data
npm run db:init

# 4. Run automated test suite
npm test

# 5. Start the platform
npm run dev
```

Open `http://localhost:5000` in your web browser.

See the complete documentation in [construction-management-platform/README.md](./construction-management-platform/README.md).
